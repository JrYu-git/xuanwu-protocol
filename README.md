# 玄武协议 (Xuanwu Protocol)

回合制战略原型 → 冷战对抗 → 机甲出击，三个阶段的完整开发史。

零依赖、无构建、不加载任何 CDN 资源，断网可玩。用浏览器打开 `index.html` 即可。

## 版本

| 时代 | 版本 | 原版号范围 | 特征 |
|---|---|---|---|
| 单文件原型 | v1.x | 1.0.0.0 → 1.11.0.0 | 全部代码在一个 HTML 里 |
| 多文件 + 冷战 | v2.x | 1.12.0.0 → 2.0.6.0 | 拆分 index/game/style，加入阵营对抗 |
| 机甲出击重做 | v3.x | 3.0.0.0 → 3.0.0.1 | 机体任务、堡垒、护盾系统 |

- 查看全部版本：`git tag`
- 切换到某一版：`git checkout v2.4.0`
- 对比两版：`git diff v2.0.0 v2.4.0`

完整的新旧版本映射与逐版变更说明见 [VERSIONS.md](VERSIONS.md)。

## 版本号规则

```
主版本.次版本.补丁
  |      |      +-- 调整、修复、文案（新增函数 <10 且体积变化 <20KB）
  |      +--------- 新增系统（新增函数 >=10 或体积 +20KB）
  +---------------- 架构级改动（拆分为多文件、核心系统重写）
```

历史版本经重新编号：原始四段号（如 `1.12.3.2`）与新版号（`v2.3.0`）的对应关系记录在每次提交信息与 VERSIONS.md 中。

## 快照结构

每个 tag 对应的快照中，该版本的主 HTML 统一命名为 `index.html`，配套 JS / CSS / 音频保留原始文件名。
